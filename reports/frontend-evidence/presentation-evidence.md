## 6. 검증 범위와 한계

- 로컬 목업(MSW)·Axios spy·로컬 브라우저 관측이다. 실서버 지연·SQL 비용·실사용자 p75는 어떤 수치에도 들어있지 않다.
- ux-* 표본은 MSW 활성 빌드라 실운영 번들·지연과 다른 조건이며, 서비스워커 경유 응답의 전송량은 관측되지 않는다(transferSize=0).
- 요청 수는 결정적 테스트 카운터(표본 1)다 — 브라우저 네트워크 경계와 다른 계층이므로 혼합하지 않는다.
- INP는 별도 측정 도구가 없어 미수집이다 — 클릭→피드백 지연으로 대체 표현하지 않는다.
- 사람 과제 수행 기록 없음 — '페르소나 사용성 평가 완료'로 표현하지 않는다. 페르소나는 구현 점검 기준으로 썼고, `persona-check.r2.raw.json`의 자동 spot-check(마커·키보드 도달·콘솔 오류)은 사람 사용성이 아니다. 390px은 뷰포트 모사, 200% 확대는 실브라우저 확대가 아닌 대체 검증이다.
- baseline.json(c8ba148)과 baseline-r2.json(40e9fda)은 커밋·fixture가 다르므로 두 run 간 개선율은 산출하지 않는다.
