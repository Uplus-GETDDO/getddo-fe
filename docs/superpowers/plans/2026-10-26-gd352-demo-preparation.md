### 부족 (BE 요청 대기)

- 추첨 시나리오 격리 이벤트 C1~C6 — 현재 실행 72건 전부 CONFIRMED/NO_ENTRIES라 실패·재개·재추첨 흐름을 보여줄 수 없다
- INACTIVE 계정 — 비활성 사용자 거절 화면 표본 없음
- 추첨 FAILED 실행 표본
- 일일 출석 미래 예약 표본(AP05 대상)
- 배송 정보 입력 계약(버튼 노출 확정 선행)

## 4. 시연 시나리오 ↔ 데이터 매핑

1. 로그인(계정 선택) → 홈(B01 배너 슬라이더·겟또타임 안내)
2. 이벤트 목록 → `/time-raffle` 상세(PLATINUM 등급 스테퍼) → 응모 201
3. `/my-tickets`(플래티넘 잔량·등급 분포) → `/my-entries`(응모 이력)
4. 미션(퀴즈/설문 제출 → 보상) → 게임 4종(플레이 → 점수·보상)
5. 알림(벨 미읽음 → 읽음 → `linkUrl` 이동) — user1~3 계정
6. 관리자: 대시보드 → 이벤트/응모 조회 → 응모권 이력(PLATINUM 행) → 어뷰징 목록·상세 evidence → 배너 관리(조회만, CRUD는 격리 환경 후)
7. (C1~C6 확보 후) 추첨 확정 → 발표 → 사용자 결과·알림 도착 → 취소·재추첨
