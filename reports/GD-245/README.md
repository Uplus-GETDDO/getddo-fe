# GD-245 R07 모바일 헤더 검증

## 결과

390×844 미션 화면에서 재현한 프로필 세로 줄바꿈을 수정했다. 브랜치는 `fix/GD-245`이며 PR 대상은 `dev`다. 배포는 수행하지 않았다.

## 변경 내용

- `UserLayout.tsx`: 모바일 로고·간격·패딩을 조정했다. 640px 미만에서는 프로필을 아바타로 축약하고 그 이상에서는 이름·설명을 한 줄 말줄임으로 표시한다. 전체 이름은 접근성 이름과 사용자 전환 팝오버에서 제공한다.
- 전체 메뉴 노출을 1280px부터로 조정했다. 그 미만에서는 기존 모바일 메뉴를 사용한다. 메뉴 항목·순서·목적지는 유지했다. 관리자 직접 진입은 1280px부터 아이콘으로, 그 미만은 기존 메뉴에서 제공한다. 시계는 1536px부터 표시한다.
- `VirtualUserSwitcher.tsx`: 현재 전체 사용자명을 트리거 접근성 이름에 포함했다. 팝오버 폭을 화면 안으로 제한하고 긴 이름을 읽을 수 있게 줄바꿈한다. 기존 선택·닫기·사용자 전환 로직을 유지했다.
- `NotificationBell.tsx`, `NotificationDrawer.tsx`: 기존 알림 버튼 2개가 모바일 헤더 공간을 사용함을 재현 중 확인했다. 버튼의 최소 터치 영역 44×44px와 축소 방지를 적용했다. 메뉴·프로필에도 동일한 최소 터치 영역을 적용했다.
- 새 UI 의존성·메뉴 구조·API·인증·설정·환경 파일은 변경하지 않았다.
- 360px·큰글씨에서는 헤더가 두 줄로 재배치된다. 프로필 이름을 세로로 줄바꿈하지 않고 버튼의 터치 영역과 화면 경계를 유지한다.

## 재현과 증거

- `capture.py before|after`: 설치된 Chrome을 헤드리스로 실행해 32개 조합을 측정한다. 서버는 `127.0.0.1:5174`다. 화면의 가상 세션만 설정하며 실제 사용자·외부 서버를 사용하지 않는다.
- `before-measurements.json`, `after-measurements.json`: 문서 너비·헤더 버튼 위치와 크기.
- `interactions.py`, `interactions.json`: 키보드 순서·포커스 스타일·팝오버 경계·상호작용·확대 측정.
- 브라우저 전용 Chromium 미설치로 시스템 Chrome을 사용했다. 스크린리더 음성 출력과 실제 휴대폰 터치는 미검증이다. 자동 접근성 스캐너는 설치하지 않았다.
- R07 밖의 320px·200% 미션 본문 넘침과 기존 포맷 경고가 남아 있다. 전체 필수 검증이 모두 통과했다고 보고하지 않는다.
