## 작업 계획과 과거 기록

[계획·인수인계 색인](superpowers/plans/README.md)에서 진행 맥락을 찾습니다.
계획·실행 프롬프트·인수인계는 작업 당시 기록이며, 구현 완료의 근거는 코드·커밋·검증 결과입니다.
기존 파일은 참조 경로를 보존하고, 완료 여부를 확인하지 않은 자료를 일괄 이동하거나 삭제하지 않습니다.

2026-10-21 승인으로 삭제한 GD-242~GD-247 완료 계획과 2026-10-19 승인으로 삭제한 로드맵·프롬프트·점검 문서는 Git 이력에서 확인합니다. 과거 R01~R25·F01~F14는 당시 작업 식별자이며 Jira 키가 아닙니다.
