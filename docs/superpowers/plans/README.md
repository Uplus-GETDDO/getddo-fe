# 계획·인수인계 기록

현재 동작의 기준은 [연동 현황](../../backend-integration-status.md)과 실제 코드이며, 이 폴더의 과거 체크박스나 프롬프트만으로 완료를 판단하지 않습니다.

## 보관 기준

- 날짜·Jira 키는 작업을 찾는 기준이며 최신 구현 여부를 보장하지 않습니다.
- 완료 계획을 이동·삭제할 때는 다른 문서·검증 스크립트의 참조를 먼저 확인합니다.
- JSON·스크린샷을 포함한 기존 파일은 경로를 유지합니다. [검증 기록 색인](../../../reports/README.md)으로 현재 대표 증거에 접근할 수 있습니다.
- 사용자 작업 중인 미추적 파일과 기존 삭제 상태는 이번 문서 정리 대상에서 제외합니다.
