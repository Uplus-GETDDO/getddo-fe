# 프론트엔드 문서

공용 정책·API 계약의 원본은 [getddo-spec](../../getddo-spec/README.md)다. 이 디렉터리는 FE 코드의 현재 상태, 구현 계획, 기술 결정을 관리한다.

## 현재 작업의 진입점

1. [도메인 맥락](CONTEXT.md): 계약을 사용할 때 지켜야 할 경계와 코드 위치.
2. [백엔드 연동 현황](backend-integration-status.md): 2026-10-22 코드 대조 결과, 남은 목업, 확인이 필요한 계약.
3. [백엔드 연동·프로젝트 완성 로드맵](superpowers/plans/2026-10-20-backend-integration-roadmap.md): 송동현 중심의 6개 통합 작업, Jira 제목, 순서와 완료 조건.
4. [작업별 실행 프롬프트](superpowers/plans/2026-10-20-backend-integration-prompts.md): 각 작업을 시작할 때 복사할 입력.
5. [관리자 추첨·이미지·UI·UX 개선 실행 문서](superpowers/plans/2026-10-21-admin-ui-ux-execution.md): 전체 개선 범위, 시작 프롬프트, 작업 순서와 인수 기준.

## 기준 문서

- [AGENTS.md](../AGENTS.md): FSD·API 호출·테스트·협업 규칙.
- [디자인 시스템](DESIGN-SYSTEM.md): 현재 토큰과 사용 기준. 실제 값은 `src/app/styles/tokens.css`다.
- [제품 맥락](product-context.md): 원 기획서·페르소나·성능 목표. 현재 구현 현황이나 확정 API 목록의 원본이 아니다.
- [FE ADR](adr/README.md): 기술 결정과 당시 이유. 과거 맥락을 현재 구현으로 해석하지 않는다.

## 과거 기록 읽기

GD-242~GD-247의 완료 계획 문서 6개는 2026-10-21 사용자 승인으로 삭제했다. 당시 계획은 Git 이력에서 확인하며, `reports/`의 검증 기록과 ADR은 보존한다. 현재 반영 여부와 잔여 작업은 커밋·연동 현황·통합 로드맵에서 확인한다. 과거 검증 결과를 소급해서 현재 상태로 바꾸지 않는다.

2026-10-19 미추적 로드맵·다음 세션 프롬프트·배포 점검 문서 3개는 사용자 요청으로 삭제했다. 과거 계획의 R01~R25·F01~F14 표기는 당시 작업 식별자이며 Jira 키가 아니다. 새 작업의 대응은 새 로드맵의 “기존 작업 정리”를 따른다. 이 참조는 삭제된 파일을 다시 읽으라는 실행 지시가 아니다.
