# README 배너와 화면 이미지

[프로젝트 README](../../../README.md) 상단의 `getddo-banner.png`는 사용자가 제공한 픽셀 아트 이미지 원본입니다. 로고와 마스코트가 있는 가로형 배너로 사용합니다.

서비스 화면 5장은 실제 배포 화면을 다시 촬영했습니다. 별도 목업이나 이미지 생성 없이 이미지 로딩을 확인한 뒤 브라우저의 본문 영역을 캡처했습니다.

- 촬영일: 2026-10-26 KST
- 배포 주소: https://getddo-fe.vercel.app
- 관측한 엔트리 청크: `index-Bq3CWmJj.js`
- 형식: 배너는 PNG 원본, 화면 캡처는 WebP·CSS 픽셀 기준
- 데이터: 배포 환경의 가상 사용자·이벤트·보상 데이터
- 작업 범위: 화면 조회와 시연 계정 선택만 수행했습니다. 응모·출석·제출·추첨·관리자 데이터 변경은 수행하지 않았습니다.
- 공개 범위: 계정 선택 화면·헤더 계정 메뉴·관리자 사용자 명단을 제외했습니다. 화면의 본문 내용을 합성하거나 조회 실패를 정상 결과로 교체하지 않았습니다.

| 파일                                             | 경로                    | 브라우저 크기 | 캡처 영역                                                                     |
| ------------------------------------------------ | ----------------------- | ------------- | ----------------------------------------------------------------------------- |
| [home-desktop.webp](home-desktop.webp)           | `/`                     | 1440×1000     | 닌텐도 배너·바로가기・상품 이미지가 표시된 겟또타임 본문                      |
| [attendance-mobile.webp](attendance-mobile.webp) | `/missions`             | 390×844       | 월간 달력을 펼친 출석 현황과 연속 출석 보너스                                 |
| [games-mobile.webp](games-mobile.webp)           | `/missions`             | 390×844       | 썸네일이 표시된 게임 카드 목록. 오른쪽 카드 일부 노출은 가로 스크롤 UI입니다. |
| [raffle-mobile.webp](raffle-mobile.webp)         | `/time-raffle/:eventId` | 430×932       | 상품 이미지부터 등급별 응모권 수량 선택·버튼까지의 대표 카드                  |
| [admin-desktop.webp](admin-desktop.webp)         | `/admin/events`         | 1440×1000     | 이벤트 검색·필터·상태별 목록                                                  |

이미지의 일정·잔액·이벤트 수는 촬영 시점의 값입니다. 배포 데이터가 바뀌면 다시 캡처합니다.
월간 달력 펼치기 외에 화면 내용을 변경하지 않았으며, 상품 이미지와 응모권 선택 영역이 한 화면 높이를 넘는 경우 본문 전체에서 해당 영역을 잘랐습니다. 따라서 캡처 높이는 브라우저 높이와 다를 수 있습니다.
관리자 대시보드 집계 조회 실패는 소개 이미지에 사용하지 않았으며 [연동 현황](../../backend-integration-status.md)에 별도 관측으로 기록했습니다.
