# 시연 운영 절차 — 계정 준비, 실패 복구, 이전 배포 복귀

> 기준: GD-260(`feat/GD-260`) 이후 배포 형태 — MSW 없음, 실서버 전용, 시연 계정은 `VITE_VIRTUAL_USERS_JSON`이 공급.

## 1. 시연 전 준비

1. **시연 계정 등록 확인** — 백엔드 DB에 시연용 USER(멤버십별)·ADMIN·INACTIVE 계정이 실제 등록돼 있는지 확인한다. `id`는 DB의 UUID다. 목업 ID(`vu-*`)는 실서버에서 401 `USER-002`가 된다.
2. **Vercel 환경변수 설정** — 프로젝트 대시보드의 환경변수에 `VITE_VIRTUAL_USERS_JSON`을 JSON 배열 한 줄로 넣는다:
    ```
    [{"id":"<uuid>","name":"김도윤","role":"USER","membership":"vip","personaLabel":"데일리 루틴러"},{"id":"<uuid>","name":"관리자","role":"ADMIN","membership":"excellent","personaLabel":null}]
    ```
    `role`은 `USER`/`ADMIN` 대문자, `membership`은 `excellent`/`vip`/`vvip` 소문자다. 값 변경은 **재배포 후에만** 반영된다(빌드 시 굽는다).
3. **격리 시연 데이터** — 마감·추첨·발표 시나리오는 서버에 실제 일정으로 준비한다. FE 가상 시계는 로컬 개발 전용이라 배포에 노출되지 않으며, 서버 마감(+5분 자동 추첨)도 실제 시각 기준이다. 발표까지 기다리는 시간을 시연 일정에 반영한다.
4. **재배포 후 확인** — 새 배포에서 로그인 화면에 설정한 계정만 보이는지, 브라우저 개발도구 Application > Service Workers에 `mockServiceWorker.js`가 없는지 확인한다. 이전 목업 배포를 쓰던 브라우저도 첫 진입 시 앱이 자동으로 이 Worker만 해제한다.

## 3. 사용자 전환·세션

- 사용자 전환은 헤더 계정 메뉴에서 한다 — 전환 즉시 전체 쿼리가 리셋돼 이전 사용자의 응모권·알림·결과가 섞이지 않는다.
- 새로고침하면 브라우저에 저장된 세션으로 같은 사용자가 유지된다. 처음 계정 선택으로 돌아가려면 `localStorage`의 `getddo-session`을 지우고 새로고침한다(개발도구 Application > Local Storage).
- 시연 계정 선택은 인증이 아니다 — `X-User-ID`/`X-User-Role` 헤더로 문맥만 전달하고 실제 권한은 서버가 DB 역할로 판정한다.

## 4. 이전 배포로 복귀

1. Vercel 대시보드 > Deployments에서 이전 정상 배포를 **Promote**한다(코드 롤백은 Vercel이 배포 단위로 처리하므로 Git 되돌리기는 필요 없다).
2. 이전 배포가 목업 하이브리드(`VITE_ENABLE_MSW`가 빌드에 true)라면 복귀 후 브라우저는 다시 목업 Worker를 등록한다 — 이후 새 배포로 돌아올 때 `serviceWorkerCleanup`이 다시 해제한다.
3. `VITE_VIRTUAL_USERS_JSON` 값 자체를 잘못 넣은 경우는 값을 고치고 **Redeploy**한다 — 환경변수 수정만으로는 이미 빌드된 배포에 반영되지 않는다.
4. 복귀 후에도 문제가면 Vercel 대시보드에서 `VITE_VIRTUAL_USERS_JSON`을 지우고 이전 목업 배포 상태로 내려 시연한다 — 이 경우 배포는 목업을 포함하므로 "실서버 시연"이 아님을 보고서에 남긴다.

## 5. 검증 스크립트

`scripts/verifyL6Browser.py`가 배포와 같은 조건(MSW 없음·계정 JSON)의 로컬 preview를 띄워 검증한다:

```bash
L6_USERS_JSON='[{"id":"<실제 uuid>","name":"...",...}, ...]' python scripts/verifyL6Browser.py
```

`/virtual-users` 미호출·Worker 자동 해제·사용자 전환 캐시 격리·가상 시계 비노출·미설정 안내·320/390px를 확인하고 `docs/superpowers/plans/L6-browser-evidence.json`에 기록한다.
