## 실제 API 읽기 표본

확인 시각은 2026-10-20 04:00:25~04:00:46 UTC(13:00 KST)다. 공개된 시연 로그인 화면의 사전 등록 ADMIN/USER를 사용했다. ID·이름·응답 원문은 이 기록에 보관하지 않았다.

- FE 진입: `https://getddo-fe.vercel.app/login`.
- FE 프록시: `https://getddo-fe.vercel.app/api/v1`.
- BE 직접 요청: `https://dzc8oneey9mmx.cloudfront.net/api/v1`.
- 로그인 선택 목록에는 ADMIN 1명·USER 5명이 있으며 모두 UUID다. 이것은 DB 전체 사용자 목록이 아니다.
- 브라우저 Service Worker는 활성 상태다. AO01·AS01·응모권 조회는 BE 주소로도 직접 GET하여 결과를 대조했다. 신규 관리자 API가 현재 하이브리드 핸들러에 없는 것도 소스에서 확인했다.
- 아래 성공 표본은 JSON 봉투·필드·HTTP 확인이다. 아직 구현되지 않은 GD-250 Zod 파서 통과나 모든 데이터 규칙의 검증으로 확대하지 않는다.

추이 28개 조회에 요약용 지급 2개가 더해졌다. 요약의 오늘·어제 사용량은 같은 Query 키로 재사용되어 별도 2개가 추가되지 않았다. 화면에는 “오늘 어뷰징 차단”과 “가상 시계 기준” 문구가 있다. AS01 전환 시 전자는 탐지 기록으로 고치고 가상 시계는 조회 기간 선택이며 서버 조작이 아님을 명확히 한다.
