1. L6 계획을 새 세션에서 읽고 승인된 계정 공급 방식·런타임 MSW 종료·Worker 정리·실서버 시간 안내를 구현한다. 기존 `VITE_VIRTUAL_USERS_JSON` 직접 소비·샘플 자동 대체 제거는 L6 사용자 문맥 승인 대상이다.
2. L5 코드의 브랜치/커밋·원격 dev 포함 여부부터 대조한다. L5를 누락한 dev로 통합 검증하지 않는다. 머지·배포는 별도 지시다.
3. 등록된 시연 계정 전환·새로고침·로그아웃의 캐시 격리, 사용자 동선·직접 상세 진입·오프라인/429/모바일 검증 준비는 외부 답변과 독립적으로 진행한다.
4. 테스트용 MSW·장애 재현·고정 fixture는 보존하고 런타임 가짜 성공만 제거한다. L2/L4의 외부 대기를 이유로 이 구현을 멈추지 않는다.
