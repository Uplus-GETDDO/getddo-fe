### Task 4: color-contrast 분석·인계 문서 (디자인 토큰 담당자용)

**Files:**

- Create: `reports/20261023-gd330-color-contrast-handoff.md`

**근거:** axe 기준선 `/admin/entries:desktop` `color-contrast` serious ×20 (`td:nth-child(3) > .hover\:underline.text-fg-brand`). `fg/brand`(`#E6007E`)가 흰 배경 위 대비 기준 미달. 사용자 결정으로 코드는 건드리지 않고 담당자가 고를 수 있는 후보 값·제약을 문서로 넘긴다.

- [ ] **Step 1: 후보 값 대비 계산 (python)**

아래 제약으로 계산해 문서에 표로 첨부한다:

- 흰 배경(`#FFFFFF`) 위 ≥4.5:1 (WCAG AA 본문)
- `surface/canvas`(`#F4F5F7`)·`brand/soft`(`#FDEBF4`) 위 ≥4.5:1 — `bg-brand-soft text-fg-brand` 뱃지 사용처가 있음
- `fg/primary`(`#1F242B`)와 ≥3:1 — `link-in-text-block` (본문 속 링크 색 구분) 유지
- 다크 모드 `fg/brand`(`#FF4DA3`)는 변경 불필요 여부도 계산해 기록

```bash
python - <<'EOF'
def lin(c):
    c /= 255
    return c / 12.92 if c <= 0.04045 else ((c + 0.055) / 1.055) ** 2.4
def lum(hexs):
    r, g, b = (int(hexs[i:i+2], 16) for i in (1, 3, 5))
    return 0.2126 * lin(r) + 0.7152 * lin(g) + 0.0722 * lin(b)
def cr(a, b):
    la, lb = lum(a), lum(b)
    lo, hi = min(la, lb), max(la, lb)
    return (hi + 0.05) / (lo + 0.05)
FG = '#1F242B'
for cand in ['#E6007E', '#D10072', '#D0006F', '#CC0070', '#C0006E', '#BC0066']:
    print(cand, 'white', round(cr(cand, '#FFFFFF'), 2),
          'canvas', round(cr(cand, '#F4F5F7'), 2),
          'brandsoft', round(cr(cand, '#FDEBF4'), 2),
          'vs-fg', round(cr(cand, FG), 2))
print('dark', round(cr('#FF4DA3', '#1F242B'), 2), 'dark-elev', round(cr('#FF4DA3', '#2B323C'), 2))
EOF
```
