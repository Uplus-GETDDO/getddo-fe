## 변경

- 마감 E03의 기존 preview 3행/full 첫 10행·더보기 범위를 유지하고 최초 실패 안내·행별 재시도를 추가했다. 다중 현황의 갱신 실패 때 기존 값을 null로 가리던 처리를 수정했다.
- E09 전체 최초 조회와 표시 행 폴링을 분리했다. 내 응모는 필터·정렬·더보기 후 행, 마이페이지는 최근 4행의 접수 이벤트만 주기 조회한다. 캐시가 있는 다중 결과는 화면 복귀·네트워크 재연결로 전체를 자동 재조회하지 않는다.
- E08의 미공개 CANCELED/NO_ENTRANTS는 종료한다. E09의 모호한 미공개 CANCELED/NOT_ENTERED/PENDING은 추측 종료하지 않는다.
- E03/E08/E09에 한정해 400/401/403/404·스키마 오류는 재시도·폴링 중단, 네트워크/5xx는 1초 후 1회 재시도, 429는 Retry-After 대기를 적용했다. 코드 없는 Axios 오류의 헤더도 해석한다.
- 429 대기 근거를 Query 수명에 보존해 수동 재시도·재마운트가 HTTP 요청을 우회하지 못하도록 했다. 초/HTTP-date와 헤더 없음(30초 FE 복구 정책)을 처리한다. 대기는 실제 경과 시간으로 계산한다.
- 최초 로딩·최초 실패·백그라운드 갱신·갱신 실패·요청 제한을 구분한다. 이전 수치·결과·성공 시각을 유지하며 KST 시각과 재시도를 표시한다. 결과 미조회 상태를 0건·미당첨으로 확정하지 않는다.
- 전체 집계는 각 결과의 마지막 조회 기준임을 안내하며, 조회된 결과 중 가장 오래된 성공 시각을 표시한다. 실패한 결과가 있으면 완전한 집계로 제시하지 않는다.
- AbortSignal을 E03/E08/E09 Axios 요청에 연결했다. 기존 키와 Query 캐시를 유지했다. SSE/WebSocket·새 dependency·전역 상태·API 계약·빌드 설정은 추가하지 않았다.

## 리뷰와 미검증 범위

- 독립 리뷰의 major 1건(NO_ENTRANTS 종료 후 발표 대기 카드 잔존)을 수정했다. 실패 재현 후 CANCELED/NO_ENTRANTS 상세 회귀 테스트가 통과했다. 증분 재리뷰는 차단 finding 0개로 승인됐다.
- 접근성은 native Button·상태 알림·행 링크 밖 재시도·의미 있는 버튼 이름을 컴포넌트 테스트와 정적 검토로 확인했다.
- 실제 브라우저의 키보드 포커스·320px/200% 확대·다크·reduced motion은 미검증이다. Browser 도구는 테스트용 Chrome 실행 파일이 없었고, DevTools는 기존 프로필 사용 중 오류, 내장 브라우저는 localhost 접속 시간 초과였다. 새 dependency나 브라우저를 설치하지 않았다.
- 실제 배포 API·실서버 Retry-After·운영 부하·배포 화면은 검증하지 않았다. 테스트가 서버의 빈도 제한 적용 범위를 확정하지 않는다.

- E09 미공개 CANCELED의 최종성, NOT_ENTERED/PENDING만 있는 종결 결과, 과거 NO_ELIGIBLE_ENTRANTS 의미는 계약 협의 대상이다. E08을 행마다 추가 호출하거나 예상 시각으로 종료하지 않는다.
