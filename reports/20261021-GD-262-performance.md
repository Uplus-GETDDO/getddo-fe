모바일의 숨겨진 내비게이션 Link는 DOM click으로 경로를 전환한다. 메뉴를 펼치는 시간·OS 입력 지연·실제 디스플레이 픽셀의 광학 측정은 포함하지 않는다. CSS/이미지/폰트의 모든 다운로드 완료나 완전한 LCP를 의미하지 않는다. FCP와 결과 준비 시점까지 관측된 LCP는 초기 진입에서만 기록한다. SPA 전환에 navigation LCP를 재사용하지 않는다.

측정 중계는 HTTP/HTTPS 스트림을 그대로 전달해 gzip·ETag·Last-Modified·Retry-After를 보존한다. API에 별도 인공 지연을 넣지 않으며 CDP 제한은 브라우저→로컬 중계 구간에 적용한다. 중계→API 시간은 이 제한을 제외한 네트워크 왕복이며 BE 내부 실행 시간은 미측정이다.

실서버 측정 도중 이벤트 수가 26→28로 바뀌고 선택 상세 ID도 달라졌다. `before.json`과 `diagnostic-live-after-partial.json`의 시간 차이는 동일 데이터의 개선 효과로 해석하지 않는다. 이후 `controlled-*`는 같은 응답 파일의 SHA-256, 같은 응답별 50ms 지연과 같은 빌드를 사용하는 통제 비교다. 이 실험의 proxyApi는 **인공 응답 시간**이며 실서버 API p95가 아니다. 정적 자산은 원래 Vite preview에서 gzip·캐시 헤더를 보존해 받는다.

고정 응답 원문은 저장소 밖 임시 파일에만 보관한다. 스크립트의 `--capture=true --fixture=<임시 경로>`로 응답을 수집한 뒤, 전후 실행에서 같은 `--fixture`를 지정한다. 재생 시 미수집 요청은 502로 실패시키며 실서버 응답으로 대체하지 않는다. 최근 30일 응모권 조회에서 실행 시각에 따라 달라지는 from/to는 같은 고정 기간 응답으로 정규화했다. 통제 실험이 정상 조회 정책의 신선도를 검증하는 자료는 아니다.

## 표본과 목표의 제한

- 최초 계획은 조건당 30회×3배치였다. 사용자가 “축소 측정 후 주요 화면 30개 검증”을 추가 승인해 전체 화면·조건당 1회×3배치(n=3, 워밍업 0회), 홈 추가 검증 10회×3배치(n=30, 배치별 워밍업 1회 제외)로 정했다. 원래 90개를 완료했다고 해석하지 않는다.
- n=3의 nearest-rank p95는 최댓값이다. 탐색적 비교이며 안정적인 모집단 p95나 작은 시간 차이의 유의성을 주장하지 않는다. 실패·표본 부족·측정 불가 사유를 함께 기록한다.
- 조회 API p95 500ms, 응모 API p95 1초, 실제 공개→접속 사용자 결과 표시 p95 2초는 `docs/product-context.md:389`의 원문 목표다. 서로 다른 구간을 섞지 않는다.
- 일반 화면의 클릭→결과 표시와 초기 번들 예산은 문서에 별도 확정 목표가 없어 **목표 미확정**으로 유지한다.
- 실제 응모·출석·제출·관리자 발표의 반복 쓰기, 공개→화면 반영의 실제 종단 측정, RUM·부하 시험은 이번 읽기 전용 측정으로 통과 판정하지 않는다.

## 비교 자료의 범위

- 비교용 원시 자료: `GD-262/controlled-before.json`, `controlled-after.json`, `controlled-*-home-1..3.json`, `before-bundle.json`, `after-bundle.json`. 실서버 요청 관측 자료는 `before.json`이다.
- 초기 측정기의 압축/캐시 중계 및 이전 DOM 준비 조건을 보완하기 전 자료는 `diagnostic-*` 또는 `pilot*`로 구분한다. 해당 시간과 중복 집계는 최종 전후 비교에 사용하지 않는다.
- 모든 요청은 GET만 허용한다. UUID는 서로 구분되는 해시로 익명화하며 응답 본문·사용자 이름·헤더 식별값·토큰은 새 원시 자료에 기록하지 않는다.

## 복귀와 상태

문제가 생기면 GD-262의 `userRoutes.tsx` 변경만 되돌리고 기존 정적 페이지 import를 복구한다. 측정 도구·원시 증거는 원인 확인을 위해 보존한다. 서버 상태·DB·의존성·배포 설정을 복구할 변경은 없다.

현재 미완료: 통제 기준선 132회 중 111회 시도(유효 105·링크 없음 6)에서 중단했다. 배치별 44/44/23회이며 마지막 저장 구간은 missions:revisit5다. 통제 변경 후 측정, 홈 n=30 전후, 65초 체류·미션 모달·페이지 이동·데스크톱·101개 이벤트 보조 측정, 실제 브라우저 회귀 검사는 미실행이다. `handoff-state.json`에 중단 상태를 기록했다. 실서버 변경 후 부분 자료와 통제 기준선을 완전한 전후 비교로 사용하지 않는다. 최종 저장 시점의 format/lint 검사 결과는 인계 문서에 기록한다.
