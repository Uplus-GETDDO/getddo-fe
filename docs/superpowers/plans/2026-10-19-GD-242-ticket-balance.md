### 브라우저 검증과 한계

- 로컬 Vite + 전체 MSW에서만 검증했다. 실제 서버에 응모·적립 요청을 보내지 않았다.
- Tab으로 재조회 버튼에 이동하고 Enter로 복구한 뒤 오류 제거와 수량 입력 활성화를 확인했다. 포커스 링도 확인했다.
- 320px와 200% 확대 상당 조건에서 새 안내와 상세 본문은 가로 넘침이 없었다. 기존 헤더의 가상 사용자 버튼은 320px에서 문서 폭을 약 391px로 늘린다. R02 밖이므로 수정하지 않았다.
- 동작 줄이기, 밝은 테마·어두운 테마를 확인했다. 새 오류 텍스트는 기존 `semantic/error-strong` 토큰을 사용하며 대비는 밝은 테마 4.83:1, 어두운 테마 6.84:1이었다. 재조회 버튼 높이는 44px다.
- 콘솔에는 의도적으로 재현한 HTTP 500과 대비 측정용 Canvas 경고가 있었다. 앱의 미처리 예외는 관찰하지 않았다. axe 자동 접근성 검사는 실행하지 않았다.
- 기존 배포 보고서·로드맵·다음 세션 프롬프트는 작업 전후 SHA256이 모두 같았다. 기존 문서의 포맷 경고는 보존했다.
