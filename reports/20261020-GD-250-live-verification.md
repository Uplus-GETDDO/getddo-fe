## 3. 브라우저 실연동 (실서버 응답 기준)

- `/admin`: AS01 1회(`stats/daily?from=2026-10-14&to=2026-10-20`, 200)로 요약·추이 렌더. 이전 방식의 조건별 지급/사용 조회 0회, 차단 목업 0회. 지급 8장(+3)·사용 6장(+6)·탐지 0건·활동 5명·활성 12명·참여율 41.7%·7일 합계 지급 69장/사용 19장.
- `/admin/users`: 실제 13행 로드(관리자 포함), “현재 활성 일반 사용자 12명” 표시, 검색·역할·상태·멤버십·UUID 필터 폼, 페이지 크기 선택.
- 사용자 상세 서랍(`?detail=`): AO02 필드 표시, 응모 이력·응모권 이력·정합성 링크 3개.
- `/admin/entries?userId=`: 해당 사용자 응모 이력 1건, 사용자 ID 링크로 상세 복귀.
- `/admin/entries?view=participants&eventId=`: 이벤트 참여자 2명(사용 응모권·최초 응모 시각), 사용자 상세 링크.
- 대시보드 “진행 중 이벤트 응모 현황” 각 행의 “참여자 조회” 링크 → `view=participants&eventId=` 연결 확인.
- `/admin/tickets?tab=histories&userId=`: 해당 사용자 전체 이력 20건(지급·사용·반환, 브론즈·실버).
- `/admin/tickets?tab=consistency&userId=`: 정합성 서랍 “일치”, 사용 가능 6장, 최근 이력 목록.
- 콘솔 오류 0건 (프록시 전환 후).

## 5. 미검증·한계

- 거절 응모·불일치·GOLD/PLATINUM은 서버에 데이터가 없어 **엔드포인트 정상·빈 페이지 실측**까지만 확인했다. 실물 표본 렌더링은 MSW 테스트 근거다.
- AS01 활동 없는 날짜는 월 경계 범위 응답의 0값 날짜로 간접 확인했으며 별도 표본은 없다.
- `%`·`_`의 서버 와일드카드 해석 여부는 “0건 매칭” 실측이 전부다.
- 200% 확대는 별도 실측 없음.
- PR 생성·dev 반영·배포는 수행하지 않았다.
