## 자료 찾기와 해석

- 파일명은 대체로 `YYYYMMDD-작업키-범위`이며, 같은 접두사의 Markdown·JSON·이미지를 함께 확인합니다.
- `gd341/`, `gd352-platinum/` 등의 하위 폴더는 해당 검증의 화면 증거입니다. README 소개용 이미지는 [별도 경로](../docs/assets/readme/README.md)에서 관리합니다.
- `BEFORE`·`before`·`after`·`r1` 등의 이름은 비교·반복 측정 표본입니다. 이전 표본을 현재 상태로 해석하지 않습니다.
- 계획 폴더의 L4~L6 증거는 기존 참조 경로를 유지합니다. [계획·인수인계 색인](../docs/superpowers/plans/README.md)에서 찾을 수 있습니다.
- 보관 기록에 적힌 통과 수·성능 수치는 해당 시점의 결과입니다. 현재 검증은 다시 실행하고 새 결과와 구분합니다.

기존 기록은 이동·삭제하지 않았습니다. 재배치가 필요하면 참조 문서를 검색한 뒤 파일별 이동 목록과 변경할 링크를 함께 검토합니다.
